# Правила для агентов props-v2

- План: `docs/PLAN_TS_3_DAYS.md`. Читай его раздел своей задачи и §2 (модель позиции, схема), §5 (инварианты).
- Исходный прототип только для чтения: `/Users/dev/code/PROP-Solana`. Ничего там не меняй.
- Трогай только файлы своей задачи. Чужие файлы не правь; если нужно изменить контракт `src/lib/core/*` или `prisma/schema.prisma`, напиши об этом в итоговом отчёте, а не правь сам (кроме агента, которому это поручено).
- Деньги и цены только `Prisma.Decimal` (decimal.js). Никаких `number` для сумм в ядре и записи в БД.
- Не добавляй зависимостей без необходимости. Сначала стандартная библиотека и то, что уже в package.json.
- Тесты: `node:test` + `tsx`. Postgres для тестов: `DATABASE_URL` из `.env.test` (docker compose service `db`, порт 54339).
- Ворота перед завершением: `npm run typecheck`, `npm test`, `npm run build` — все зелёные. Если что-то не проходит из-за чужого кода, опиши в отчёте.
- В конце: `git add -A && git commit -m "<кратко что сделано>"` в своей ветке. Без Co-Authored-By и подписей.
- Итоговый ответ: что сделано, какие ворота прошли (с выводом), что осталось или нарушено.
- Никогда не останавливай, не удаляй и не меняй чужие Docker-контейнеры, тома и проекты. Только сервисы из docker-compose.yml этого репозитория. Если порт занят — сообщи в отчёте.
- Prisma: в тестах используй `prisma db push --force-reset` только для своей тестовой базы из .env.test.
